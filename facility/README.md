# Отчёт

## Решения

### 1. Жадный алгоритм
Открываем все магазины. Для каждого посетителя в порядке убывания demand 
берём ближайший магазин с достаточной оставшейся capacity

Файл: greedy.py

### 2. Улучшенный жадный алгоритм
Сортируем клиентов по убывания demand и в этом порядке назначаем им магазины. Перед этим
находим общий список $K$ ближайних магазинов для каждого клиента. По этому списку для текущего
клиента ищем магазин с подходящим остаточным capacity и минимальным значением 
(расстояние между i-ым магазином и j-ым клиентом) + open_bias $*$ (стоимость открытия i-го магазина).
Если такой магазин не нашелся, находим среди всех первый с достаточным capacity.
Пробуем несколько значений параметра open_bias

Файл: greedy_improved.py

### 3. Генетика
Популяцией является набор распределений магазинов по клиентам.
Создаю начальную популяцию с помощью жадного алгоритма из предыдущего решения. Далее, в течение таймера
пытаюсь улучшать решение. Для получения следующей популяции сортирую текущую по увеличению целевой функции 
и оставляю несколько лучших генов, а также скрещиваю гены, победившие в турнире, затем к ним применяется
случайная мутация (случайным клинетам назначить случайные магазины), мутированные гены исправляются до валидного решения. 
В конце обновляю ответ и перехожу к следующему шагу эволюции

Файл: genetic.py

### 4. Генетика с дополнительной мутацией
Улучшение предыдущего решения, где была добавлена менее жесткая мутация, которая переназначает случайному
клиенту магазин на один из ближайших, а не на случайный, как в первой мутации. При построении новой популяции с  определённой вероятностью 
выбирается одна из двух мутаций: добавленая или из первого решения генетикой
