## Решения

### 1. Метод ближайшего соседа с бэктрекингом (рекурсия)
Перебираем m стартовых вершин. Находим k ближайших непосещённых соседей и спускаемся в каждого, пока глубина меньше max_depth.
Если глубина больше или равна max_depth, добираем жадно методом ближайшего соседа

Файл: nn_backtracking_recursion.py

### 2. Муравьиный алгоритм
Получаю стартовое решение методом ближайшего соседа из первой вершины. Далее, в течение действия
таймера запускаю колонию и обновляю феромоны. Для перехода к следующей вершине насчитываю вероятности по стандартной формуле, затем
их суммирую и выбираю случайный порог от нуля до значения суммы. Если сумма вероятностей на префиксе до i-ой вершины включительно впервые не меньше порога,
то эта вершины будет следующей.
В качестве дополнительной эвристики обновляю феромоны до начального значения, если несколько итераций подряд нет улучшений .

Файл: aco.py

### 3. Муравьиный алгоритм + 2-opt
К предыдущему алгоритму добавил 2-opt. Теперь каждое решение муравья с определённой вероятностью будет
прогоняться через 2-opt, а также итоговое решение колонии с большим числом попыток.
Ещё одно улучшение - общий список ближайших $K$ соседей для каждой вершины, который используется для определения следующей вершины,
куда пойдёт очередной муравей

Файл: aco_2opt.py
