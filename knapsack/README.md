### 2. Метод ветвей и границ
Попробуем что-нибудь менее дорогое, чем дп.

Сортируем предметы по убыванию удельной стоимости. Спускаемся по дереву
в порядке сортировки. В каждой вершине рассматриваем два варианта - брать или не брать предмет.
Для этого находим верхнюю границу на ответ в обоих случаях: жадно добираем предметы, 
пока позволяет вес, + оценка, если рассмотрены не все предметы. Если верхняя оценка больше текущего максимального ответа,
то кладём вершину в очередь и переходим к следующей

Файл: bb.py

### 3. Жадные алгоритмы
Метод ветвей и границ может плохо работать по времени в некоторых случаях, например, тест ks_200_0.
Попробуем более быстрые решения.

Запустим 3 вариации жадного алгоритма: по удельной стоимости, по стоимости и по весу, а также 
в отдельной функции будем случайно шафлить предметы и брать их в этом порядке. Из четырёх ответов
выберем лучший

Файл: greedy.py
