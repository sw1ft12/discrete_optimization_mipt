## Решения

### 1. Жадный алгоритм
На кадом шаге берём множество с минимальным значением отношения стоимости множества 
к количеству непокрытых элементов, покрывающихся этим множеством

Файл: greedy.py

### 2. ACO + MMAS
Стандартный ACO с MMAS, где в качестве эвристики выступает отношение числа непокрытых
элементов, которое покрывает текущее множество, к стоимости этого множества. На каждой итерации запускаются
муравьи, пока не закончится таймер. На очередном шаге находим лучшее решение и обновляем феромоны

Файл: aco.py

### Результаты

но в среднем получаются такие результаты:

### 3. ACO + MMAS + ретраи
Попытка улучшения предыдущего решения. Добавил ретраи и случайное обновление всех феромонов,
если некоторое время нет улучшений. Также теперь параметры $\alpha$ и $\beta$ в формуле вероятности
выбираются на каждом запуске муравья случайно из некоторого списка

Файл: aco_improved.py

### 4. ACO + MMAS + отжиг
Изменения из третьего решения ухудшили точность. Вернулся к первой версии ACO+MMAS, 
но добавил отжиг каждого решения муравья, а также длительный отжиг финального решения,
которое выдал ACO. В отжиге для перехода к соседу гененирую случайное число от 0 до 1. 
По этому числу определяется действие для перехода: выкинуть одно множество, добавить одно множество, 
добавить и удалить $k$ множеств (k-opt); в конце жадно добираются множества до валидного ответа с последующим
удалением ненужных множества. Если температура становится слишком маленькой или некоторое количество попыток 
нет улучшений, то температура повышается

Файл: aco_annealing.py
