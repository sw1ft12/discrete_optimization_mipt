# Отчёт

## Решения

### 1. Жадный алгоритм
На кадом шаге берём множество с минимальным значением отношения стоимости множества к количеству непокрытых элементов, покрывающихся этим множеством

### Результаты

| Test |  Cost  |
| ------------- |:------:|
| sc_157_0      | 102100 |
| sc_330_0      |   30   |
| sc_1000_11    |  170   |
| sc_5000_1     |   36   | 
| sc_10000_5    |   76   |
| sc_10000_2    |  192   |


### 2. ACO + MMAS
Стандартный ACO с MMAS, где в качестве эвристики выступает отношение числа непокрытых
элементов, которое покрывает текущее множество, к стоимости этого множества. На каждой итерации запускаются
муравьи, пока не закончится таймер. На очередном шаге находим лучшее решение и обновляем феромоны

### Результаты

Из-за случайности ответ иногда может отличаться, но в среднем получаются такие результаты:
